# Browser Light Scheduler

A simple web-based interface to schedule ON and OFF times for lights.

## 🌟 Features

- Set ON and OFF times using time input fields
- Clean and minimal user interface
- Easily extendable for real-world light control systems

## 📂 Project Structure
- backend: Contains all of the project's backend
- frontend: Contains all the visuals (html and css for styling)

## 🚀 How to Use

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Choose the ON and OFF times using the form.
4. Click the **Set Schedule** button.
